# FoodieExpress Order Management System

## 📌 Project Overview

FoodieExpress Order Management System is a Python-based application developed to manage customer orders and calculate order costs efficiently.

The system provides a simple graphical user interface (GUI) and uses SQLite for database management. It allows users to enter customer details, select an order type, calculate food costs, delivery charges, discounts, and the final total cost.

## 🛠️ Technologies Used

* Python
* Tkinter
* SQLite
* Object-Oriented Programming (OOP)

## ✨ Main Features

* Customer name validation
* Order type selection
* Food cost calculation
* Delivery distance validation
* Delivery charge calculation
* Customer discount calculation
* Final total cost calculation
* SQLite database integration
* User-friendly graphical interface

## 💰 Calculation Logic

The system calculates the order cost based on the following rules:

* Food Cost = Price × Quantity
* Orders with a food cost of Rs. 5,000 or more receive free delivery.
* Orders below Rs. 5,000 are charged Rs. 50 per kilometre.
* VIP customers receive a 20% discount.
* Premium customers receive a 10% discount.
* Regular customers do not receive a discount.
